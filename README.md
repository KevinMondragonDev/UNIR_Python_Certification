# 🐍 Master Python Certification

Repositorio de estudio y práctica para la certificación de Python dentro del programa de **Maestría en Big Data**.

## 📁 Estructura del Proyecto

```
master_python_certification/
├── fundamentals/       # Fundamentos del lenguaje Python
│   └── helloWorld.py
├── notas/              # Notas y comandos de referencia
│   └── comandos_de_inicio.txt
└── README.md
```

## 🚀 Configuración del Entorno

Antes de empezar, crea y activa el entorno de Conda con Python 3.10:

```powershell
# 1. Crear el entorno
conda create --name desarrollo python=3.10

# 2. Activar el entorno
conda activate desarrollo
```

## 🛠️ Tecnologías

- **Python 3.10+**
- **Conda** para gestión de entornos virtuales
